# ArmGuard 软件商店（宝塔式表格列表）设计文档

- **创建日期**：2026-09-04
- **状态**：已评审通过 (Approved)
- **目标**：将 ArmGuard 面板的「软件商店」从传统的 3 列卡片网格布局，重构为参考宝塔面板经典布局的高信息密度表格列表视图（Table View），去除商业版收费列与广告横幅，打造极致清爽的开源 Linux 运维体验。

---

## 1. 目标与设计原则

1. **高信息密度与易对比性**：
   - 相比大卡片，表格形式能够在单个屏幕内浏览更多应用，方便横向对比应用类型、版本、状态与管理路径。
2. **纯粹开源，去除冗余商业要素**：
   - 彻底移除宝塔面板中的商业广告横幅（「企业版特权/立即购买」）；
   - 移除「价格/到期时间」列，所有软件均为开源免费，凸显 Linux 原生应用与 ARM64 汇编优化生态。
3. **100% 继承成熟交互与插件生态**：
   - 完全兼容现有的全部插件弹窗（如 WarpPluginModal.vue 的双栈网络控制台）；
   - 兼容通用配置管理（Nginx / PHP / Redis 可视化参数与文件修改）；
   - 兼容一键安装流式日志终端弹窗。

---

## 2. 界面布局与组件规范

### 2.1 顶部操作工具栏 (Top Toolbar)
- **左侧分类选择器**：
  - 标签文本：应用分类；
  - 胶囊分类切换组：
    - 全部（默认，带绿色高亮）
    - 已安装（徽标显示已安装软件数，例如 已安装 (4)）
    - 运行环境（Web 服务器与运行库：Nginx、PHP、Node.js 等）
    - 数据库与缓存（MySQL、Redis、SQLite、phpMyAdmin）
    - 网络与穿透（Cloudflare WARP、WireGuard 等）
    - 安全与运维（Fail2ban、FTP 服务、Docker）
- **右侧搜索与刷新**：
  - 实时模糊搜索框（支持按软件名称、别名与描述过滤）；
  - 一键刷新服务运行状态按钮。

### 2.2 核心表格列设计 (Table Schema)

| 列序号 | 列名称 | 宽度建议 | 展示内容与交互规范 |
| :--- | :--- | :--- | :--- |
| **Col 1** | **软件名称** | ~200px | 应用专属图标（40x40 圆角玻璃拟态背景）+ 软件名称 + 当前/最新版本号 |
| **Col 2** | **开发商** | ~80px | 官方 或 开源社区（灰阶文本） |
| **Col 3** | **说明** | 自适应 (flex) | 软件功能简介，右侧带有 ARM64 优化特性徽标（如 NEON 汇编优化、预编译秒装） |
| **Col 4** | **位置** | ~90px | 已安装服务显示 📁 文件夹图标，悬浮 tooltip 显示安装目录（如 /etc/nginx），点击复制路径；未安装显示 -- |
| **Col 5** | **状态** | ~90px | 运行中显示 🟢 运行中，停止显示 ⏸️ 已停止，未安装显示 -- |
| **Col 6** | **首页显示** | ~90px | 现代化 Switch 滑块开关，开启后将服务状态快捷卡片同步至 Dashboard 首页，状态保存在 localStorage |
| **Col 7** | **操作** | ~200px | **未安装**：高亮绿色 一键安装 按钮；<br>**已安装**：操作按钮组：设置（打开可视化配置或 WARP 控制台）、启动/停止/重载、卸载 |

## 3. 数据流与交互逻辑

1. **状态驱动与事件总线 (eventBus)**：
   - 监听 EVENTS.APPS_UPDATED 与 EVENTS.WARP_UPDATED，实时更新表格中的状态指示灯与首页显示开关；
   - 切换服务状态（如启动/停止 Nginx 或断开 WARP）后，发送广播通知各依赖模块。
2. **首页显示切换机制 (Home Display Sync)**：
   - 读取并写入 localStorage.getItem('armguard_home_apps')（JSON 字符串数组存储 pp.key）；
   - 首页 Dashboard 动态渲染用户选定的应用状态卡片。
3. **弹窗解耦调用**：
   - 当点击应用为 warp 的「设置」时，自动呼出专属 WarpPluginModal；
   - 当点击其他已安装应用（如 
ginx、php、
edis）的「设置」时，呼出通用的可视化配置管理弹窗。

---

## 4. 响应式与自适应支持

- 在大屏（桌面端）上以标准的宽屏表格展现；
- 在中小型屏幕（平板或移动端），表格容器采用 overflow-x-auto 横向平滑滚动，并保持操作列与首列视差平顺，确保各列信息不挤压变形。
